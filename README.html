How to use the academy

Start learning locally in your browser.

Academy HomeTraining Simulator

Getting started

  1. Extract the ZIP archive to a folder.
  2. Open index.html in Chrome, Safari or Edge.
  3. Select Day 00 and follow the lesson sequence.
  4. Use the simulator link from any lesson for command practice.

No Python, Node.js, Docker, kubectl or Kubernetes cluster is required to view the course or run the educational simulator.

Architecture and animation

Each lesson contains its own topic-specific SVG architecture rendered by local JavaScript. Click a component to read its responsibility. Use Play, Pause, Previous, Next, Restart and the speed selector to follow the operational sequence. The active workflow step highlights the corresponding architecture component.

Day 04 contains an expanded apply lifecycle, asynchronous reconciliation animation and selectable failure-injection scenarios.

Simulator safety and capabilities

The simulator is intentionally a mock terminal. It supports a training subset of Linux, Docker, kubectl and Helm commands, simulated cluster state, basic failure injection, a 20-question assessment, scoring and local progress tracking. It does not invoke operating-system processes, contact a Kubernetes API or execute real commands.

Progress and privacy

Lesson completion and assessment results are stored in the browser's localStorage on the device and browser where the student uses the academy. Clearing site data can remove this progress. The academy does not send progress to a server.

Important operational caveats

  • Architecture diagrams are teaching models; real distributions may differ in networking, admission, storage and cloud integrations.
  • Command output is illustrative simulator output, not a guarantee of real-cluster output.
  • For production changes, use approved environments, change control, least privilege and official version-specific documentation.
