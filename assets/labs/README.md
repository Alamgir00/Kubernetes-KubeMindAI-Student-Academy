# KubeMindAI – Student Lab Pack

Each day has a README.md and, where applicable, YAML files.

Run commands in your own dedicated AWS Ubuntu EC2 training environment.
These exercises are educational. Do not run failure injection in production.
Some advanced labs require additional components, such as a storage provisioner,
Metrics Server, an Ingress controller, Helm, Argo CD or Prometheus.

Start with day-01-architecture and progress in order.
